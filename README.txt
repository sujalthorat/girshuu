GRISHUU — OUR LOVE STORY WEBSITE
================================

FILES
- index.html        Website structure and text
- style.css         Dark romantic styling and responsive layout
- script.js         Animations, menu, music button, photo viewer, surprise
- photos/1.jpg      Replace with your first photo together
- photos/2.jpg      Replace with your second photo together
- photos/3.jpg      Replace with your third photo together
- music/love-song.mp3  Optional MP3 for the music button

ADD YOUR 3 PHOTOS
1. Choose three photos you are both comfortable sharing.
2. Copy them into the photos folder.
3. Rename them exactly: 1.jpg, 2.jpg, and 3.jpg.
4. If your photos are PNG or WEBP, either convert them to JPG or update the matching
   image src values in index.html.
5. Open index.html in your browser to test.

ADD MUSIC
1. Create a folder named music (already included).
2. Add an MP3 you have permission to use and name it love-song.mp3.
3. The visitor must tap the music button because browsers generally block autoplay.

CUSTOMISE THE TEXT
Open index.html in VS Code or another text editor. Search for text like
"Our Love Story", "My dearest Grishuu", and the surprise message and edit it.
Avoid putting private messages or photos online unless both people are comfortable.

TEST LOCALLY
- Easiest: open index.html in your browser.
- Recommended: in VS Code, install the Live Server extension, right-click index.html,
  then choose "Open with Live Server".

PUBLISH FREE WITH NETLIFY
1. Keep index.html, style.css, script.js, photos/, and music/ together in one folder.
2. Visit https://app.netlify.com/drop in your browser.
3. Drag and drop the whole project folder (or a ZIP containing the files) into the page.
4. Wait for deployment, then copy the website URL it gives you.
5. Open the URL on your phone to test it before sharing.

PUBLISH WITH VERCEL
1. Upload the project to a GitHub repository.
2. Sign in at https://vercel.com and choose Add New Project.
3. Import the repository and deploy with the default static settings.
4. Vercel will provide a public URL.

NOTE
Google Fonts require internet access; the site still falls back to system fonts if offline.
The supplied project does not include copyrighted music or personal photos; add your own.
